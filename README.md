# Mentor Tracker

Trang theo dõi học viên mentor (US và Việt Nam): bước hiện tại, số ngày so với chuẩn,
việc học viên cần làm tuần này, việc mentor cần hỗ trợ, nhật ký meeting.

- `index.html`: một file duy nhất (HTML, CSS, JS thuần). Nội dung 10 bước (Playbook) nằm ở mảng `PB` đầu phần script.
- Bản đang chạy là artifact trên claude.ai, lưu dữ liệu bằng capability `db` (collection `students` và `meetings`).
- Repo này công khai nên KHÔNG chứa dữ liệu học viên. Không commit tên, email, số điện thoại học viên.
